# Sistema de Gestión de Soporte Técnico

Proyecto desarrollado para la Evaluación N°2 de Electivo Angular.

## Autor

Anthony Rebolledo

## Descripción

Aplicación web para la gestión de tickets de soporte técnico.

Permite (En fase de Prueba):

- Listar tickets
- Registrar tickets
- Editar tickets
- Eliminar tickets
- Persistir información en MySQL mediante una API REST

## Tecnologías utilizadas

### Frontend

- Angular 22
- TypeScript
- HTML
- CSS

### Backend

- Node.js
- Express
- MySQL2
- CORS

### Base de Datos

- MySQL
